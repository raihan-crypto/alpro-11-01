Algoritma membeli minuman dari vending machine
Langkah-langkah:

1. Ambil uang dari dompet
2. Masukan uang ke dalam vending machine
3. pilih minuman yang ingin dibeli 
4. Tunggu minuman keluar dari vending machine
5. Ambil minuman
6. Jika ada kembalian maka 
    - tunggu mesin hingga mengeluarkan uang kembalian
    - ambil uang kembalian 
7. Jika tidak ada kembalian maka program selesai
